## Licences

### Le contenu des fiches

**Creative Commons Attribution 4.0 International (CC BY 4.0).**

Vous pouvez le partager, l'adapter et le réutiliser, y compris commercialement, à condition
de citer la source et d'indiquer si vous l'avez modifié. Le texte complet de la licence est
dans le dépôt, sous `LICENSE-CONTENT`.

### Le code des exemples

**Licence MIT.**

Les extraits de code des fiches, le code du site et les scripts de contrôle sont sous licence
MIT. Vous pouvez les copier dans votre projet sans rien demander. Le texte complet est dans
le dépôt, sous `LICENSE`.

Ce choix est délibéré : un catalogue d'alternatives dont on ne pourrait pas copier le code
n'aurait pas beaucoup d'intérêt.

## Polices

Les trois familles sont libres, auto-hébergées, sous-ensemblées au latin utile au français et
à l'anglais, et servies en woff2 depuis ce domaine. Aucune n'est chargée depuis un service
tiers.

contenu.

## Méthodologies citées

Les ordres de grandeur d'empreinte employés dans les fiches s'appuient sur les travaux publiés
listés et cités nommément sur la page [méthodologie](/fr/methodologie) :

- Green Algorithms — Lannelongue, Grealey et Inouye, *Advanced Science*, 2021
- Estimating the Carbon Footprint of BLOOM — Luccioni, Viguier et Ligozat, 2022
- Software Carbon Intensity — Green Software Foundation, devenue ISO/IEC 21031
- AFNOR SPEC 2314, Référentiel général pour l'IA frugale — 2024
- Boavizta — données et outils ouverts sur l'impact du numérique

Ces travaux ne sont pas affiliés à Overkill et n'en cautionnent pas le contenu.

## Outils employés pour construire le site

Astro, Tailwind CSS, Shiki, Zod, Playwright, pytest, scikit-learn, NumPy, fontTools, et le
dictionnaire français Hunspell. Tous libres.
