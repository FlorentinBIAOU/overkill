need:
  fr: "Obtenir le texte d’un document PDF, page par page, dans l’ordre où il se lit."
  en: "Get the text of a PDF document, page by page, in the order it reads."

scenario:
  fr: "On voit envoyer un PDF entier à un modèle généraliste avec la consigne « donne-moi le texte », sans avoir essayé de le lire. Les caractères sont pourtant dans le fichier, exactement : un PDF numérique range les instructions pour les dessiner, et une bibliothèque les rend sans rien reconnaître ni rien inventer. Le seul vrai problème est ailleurs, et un modèle ne le résout pas mieux : le fichier dit où chaque mot est posé, jamais dans quel ordre on le lit."
  en: "Sending a whole PDF to a general-purpose model with the instruction “give me the text”, without having tried to read it, is a common sight. Yet the characters are in the file, exactly: a born-digital PDF stores the instructions for drawing them, and a library returns them without recognising or inventing anything. The only real problem is elsewhere, and a model does not solve it better: the file says where each word sits, never in which order it is read."

  - level: N1
    available: false
    unavailable_reason:
      fr: "Il n’y a rien à apprendre du contenu : les caractères sont écrits dans le fichier, et aucun modèle ne les rendra plus exacts. La seule décision de cette fiche — où sont les colonnes — se prend sur une projection des positions des mots, c’est-à-dire sur une bande vide de vingt-cinq points ; un classifieur entraîné sur des mises en page annotées donnerait la même réponse avec un jeu de données à constituer."
      en: "There is nothing to learn from the content: the characters are written in the file, and no model will make them more exact. The one decision this entry takes — where the columns are — comes from projecting the words’ positions, that is, from an empty band twenty-five points wide; a classifier trained on annotated layouts would give the same answer with a dataset to assemble first."

  - level: N2
    available: false
    unavailable_reason:
      fr: "Les modèles d’analyse de mise en page existent, et ils servent sur des pages dont l’ordre de lecture est réellement difficile : un journal, un formulaire, une affiche. Ils demandent de rendre la page en image, ce qui coûte plus cher que tout ce que fait cette fiche, et ils ne changent rien au texte lui-même, qui est déjà exact. Le gain se limiterait aux mises en page que la recherche de gouttières manque, et le prix est un modèle résident sur chaque machine qui lit un PDF."
      en: "Layout analysis models exist, and they are useful on pages whose reading order is genuinely hard: a newspaper, a form, a poster. They require rendering the page to an image, which costs more than everything this entry does, and they change nothing about the text itself, which is already exact. The gain would be limited to layouts the gutter search misses, and the price is a resident model on every machine that reads a PDF."

  - level: N3
    available: false
    unavailable_reason:
      fr: "Un modèle généraliste rend un texte qui ressemble à celui du document : sur un contrat ou une facture, la différence entre « ressemble » et « est » porte un nom. Le fichier contient le texte exact, et la lecture se vérifie — chaque caractère rendu se retrouve dans le flux de contenu. S’y ajoutent une sortie de données par document et une facture par page, pour un travail que la même machine fait en quelques millisecondes."
      en: "A general-purpose model returns a text that resembles the document’s: on a contract or an invoice, the difference between “resembles” and “is” has a name. The file holds the exact text, and the reading can be checked — every character returned is found in the content stream. Add to that one data egress per document and a bill per page, for work the same machine does in milliseconds."

verdict_rationale:
  fr: "N0, parce que le texte est dans le fichier et qu’aucune reconnaissance n’a lieu : ce que rend la bibliothèque est ce que le document contient, au caractère près. Le seul travail à faire est l’ordre de lecture, et il se fait sans modèle : une page à deux colonnes, dessinée ligne par ligne comme l’exportent beaucoup de traitements de texte, donne « La boulangerie Martin fête Clémentine Martin a repris » quand on la lit naïvement, et la recherche des gouttières la remet dans l’ordre. Ce que la fiche refuse de faire est aussi important : un mot coupé en fin de ligne reste coupé, parce que le recoller ferait de « Boulogne- » et « Billancourt » un seul mot une fois sur deux."
  en: "N0, because the text is in the file and no recognition takes place: what the library returns is what the document holds, character for character. The only work left is the reading order, and it needs no model: a two-column page, drawn line by line as many word processors export it, reads as “La boulangerie Martin fête Clémentine Martin a repris” when taken naïvely, and the gutter search puts it back in order. What this entry refuses to do matters as much: a word cut at the end of a line stays cut, because gluing it back would make “Boulogne-” and “Billancourt” one word every other time."
