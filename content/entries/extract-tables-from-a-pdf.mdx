scenario:
  fr: "On voit envoyer un PDF entier à un modèle de vision avec la consigne « rends-moi le tableau en CSV ». Un tableau dans un PDF n’est pourtant pas une image : c’est du texte posé à des coordonnées, souvent avec les filets qui disent où sont les cellules, et une bibliothèque lit les deux. La question n’est donc pas de reconnaître le tableau mais de savoir, sur chaque document, si la grille a été lue ou devinée — parce que les deux lectures ne donnent pas le même résultat, et que la seconde se trompe en silence."
  en: "Sending a whole PDF to a vision model with the instruction “give me the table as CSV” is a common sight. But a table in a PDF is not an image: it is text placed at coordinates, often with the rules that say where the cells are, and a library reads both. So the question is not recognising the table but knowing, for each document, whether the grid was read or guessed — because the two readings do not give the same result, and the second one is quietly wrong."

verdict_rationale:
  fr: "N0, parce que le texte et les filets sont dans le fichier et qu’une bibliothèque les lit : `pdfplumber` trouve les cellules là où la page les a tracées, et la lecture est exacte. Ce que la fiche ajoute est le repli — deviner les colonnes d’après la position des mots quand il n’y a pas de filet — écrit ici dans les deux langages plutôt qu’emprunté, parce que celui de `pdfplumber` coupe une cellule plus large que sa colonne et rend « Prix H » pour « Prix HT ». Et surtout, le rapport dit laquelle des deux lectures a répondu : c’est la seule façon honnête de rendre une grille dont on ne sait pas si elle était écrite ou déduite."
  en: "N0, because the text and the rules are in the file and a library reads them: pdfplumber finds the cells where the page drew them, and the reading is exact. What this entry adds is the fallback — guessing the columns from where the words sit when there is no rule — written here in both languages rather than borrowed, because pdfplumber’s own cuts a cell wider than its column and returns “Prix H” for “Prix HT”. And above all, the report says which of the two readings answered: that is the only honest way to return a grid you cannot otherwise tell was written or inferred."
