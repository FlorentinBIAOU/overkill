scenario:
  fr: "On voit envoyer une page entière à un modèle pour qu’il en rende « tous les liens ». Un href est pourtant un attribut : il est écrit, en clair, et le lire est une analyse syntaxique. Le seul vrai travail est de dire où chaque lien mène, et c’est là que les choses se compliquent — pas parce que c’est difficile, mais parce que les deux langages de cette fiche ne répondent pas la même chose, et que celui qui a raison n’est pas celui qu’on croit."
  en: "Sending a whole page to a model to get back “all the links” is a common sight. But an href is an attribute: it is written down, in plain sight, and reading it is parsing. The only real work is saying where each link leads, and that is where it gets complicated — not because it is hard, but because the two languages on this page do not answer the same thing, and the one that is right is not the one you would guess."

verdict_rationale:
  fr: "N0, parce que l’adresse est écrite dans la page et que la résoudre est une suite de règles publiées. Ce que cette fiche apporte tient à la mesure qu’elle a faite : sur trente-huit adresses, `urllib.parse.urljoin` et `new URL` répondent différemment sept fois. La plus frappante est l’antislash — `href=\"\\\\chemin\"` donne un chemin de votre site avec la RFC 3986 et l’hôte `chemin` avec la norme WHATWG, qui est celle des navigateurs. Comme la question posée est « où le lecteur va-t-il atterrir », l’extrait Python a été amené à la réponse du navigateur : nettoyage des bords, antislash, casse de l’hôte, punycode, port par défaut, encodage des espaces et des accents. Les deux extraits rendent désormais le même rapport sur les trente-huit adresses. Le reste est de la discipline : la base est exigée et rendue, l’élément `<base href>` la remplace, et ce qui n’est pas une adresse — `javascript:`, un href vide — est écarté avec sa raison plutôt que rendu comme un lien."
  en: "N0, because the address is written in the page and resolving it is a published set of rules. What this entry adds comes from the measurement it made: over thirty-eight addresses, urllib.parse.urljoin and new URL answer differently seven times. The most striking is the backslash — href=\"\\\\chemin\" gives a path on your own site under RFC 3986 and the host `chemin` under the WHATWG standard, which is the browsers’. Since the question being asked is “where will the reader land”, the Python snippet was brought up to the browser’s answer: edge cleaning, backslashes, host case, punycode, default port, encoding of spaces and accents. The two snippets now return the same report over all thirty-eight addresses. The rest is discipline: the base is required and returned, the `<base href>` element replaces it, and what is not an address — `javascript:`, an empty href — is dropped with its reason rather than returned as a link."
